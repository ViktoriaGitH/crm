# CRM за уебинарни лийдове

Сетърите взимат лийдове, звънят и отбелязват статус. Записаните разговори влизат директно в Cal.com календара на клоузъра.

- **Роли:** Админ (всичко), Сетър (взима и звъни), Клоузър (вижда своите разговори)
- **Статуси:** Нов · Вдигна · Не вдигна · Грешен номер · Фолоу ъп (с дата и час) · Записан разговор (час от Cal.com)
- **Импорт:** CSV (UTF-8/UTF-16, със запетая или табулация) и Excel .xlsx. Дубликатите се пропускат по телефон или имейл.
- **Теми:** тъмна (черно и тъмночервено) и светла
- Без настроена база сайтът се отваря в **демо режим**. Може да се отвори и с `?demo`.

## Пускане (еднократно)

1. **Supabase → SQL Editor → New query.** Постави целия `supabase/schema.sql` и натисни **Run**.
2. **Supabase → Authentication → Sign In / Providers.** Изключи **Allow new users to sign up**. Така само админът създава акаунти.
3. **Supabase → Authentication → Users → Add user → Create new user.** Въведи своя имейл и парола и отметни „Auto Confirm“. **Първият потребител става Админ.**
4. **Vercel → Add New → Project → Import** това хранилище. В **Environment Variables** добави:
   - `VITE_SUPABASE_URL`: Project URL, от Supabase → Project Settings → API
   - `VITE_SUPABASE_ANON_KEY`: ключът `anon` / `publishable`
   - `SUPABASE_SERVICE_ROLE_KEY`: ключът `service_role` / `secret`. Той е **таен**: слага се само във Vercel, никога в кода.
5. **Deploy.** Влез с акаунта от стъпка 3. В **Екип** създай сетъри и клоузър. На клоузъра постави Cal.com линка му, например `cal.com/ime/razgovor`.

## Как работи сигурността

Правата се пазят в самата база (Row Level Security):
- Сетърът вижда само свободни лийдове и своите.
- Сетърът не може да вземе вече взет лийд. Взимането е атомарно: ако двама натиснат едновременно, лийдът получава само единият.
- Сетърът не може да прехвърли лийд на друг, нито ръчно да сложи „Записан разговор“. Това става само при истинско записване в Cal.com.
- Клоузърът вижда само записаните при него разговори.
- Спрените акаунти не виждат нищо и не могат да влизат.

Тестове на правата: `npm test`
